# ZOOM COLLECTION — Frontend Demo V3

A polished fashion-store frontend demo with a client-friendly admin dashboard.

## Included
- Premium neutral storefront (Home, About, Collection, Contact)
- Smooth left-side mobile navigation drawer
- Product listing + product detail pages
- Bag / Add to Cart
- Full checkout form: name, phone, city, area, address, postal code, payment method
- WhatsApp order handoff to **+92 346 8890002**
- Admin login styled like a modern SaaS dashboard
- Responsive admin sidebar with Dashboard / Products / Orders / Settings
- Add / Edit / Delete products
- Category, price, old price, stock, status, sizes, description
- Up to 3 product photos with live previews
- Product search + category filter
- Demo order inbox
- LocalStorage demo persistence

## Important
This is still a **frontend demo** for showing the shopkeeper. Product data, images and demo orders are stored in the browser's LocalStorage, so different devices/browsers do not share the same data.

After the design is approved, connect the same UI to Laravel + MySQL/API + real image storage + real authentication. The WhatsApp order handoff can then be replaced/extended with a proper order system and payment gateway.
